# Список задач

Тестовое задание ZalogHub: список задач на React и TypeScript (Vite).

На задание ушло около трех часов.

## Что умеет

- добавить задачу через поле и кнопку «Добавить»;
- пустую строку и строку из пробелов добавить нельзя;
- отметить задачу выполненной и вернуть обратно, выполненная зачёркнута;
- удалить задачу;
- показать все, только активные или только выполненные;
- сохранить список в браузере: после обновления страницы задачи остаются.

## Запуск

Нужен Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

Сборка и проверка:

```bash
npm run lint
npm run build
```

Готовая сборка открывается через `npm run preview`.
